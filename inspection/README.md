## Native frame companions

[Native frame companions](native.html) is a separate, bounded inspector for the two recordings and 42 native PNGs published at derived revision `4b0870f45eac36c53b1084305934471ee8dd273b`. The matching Standard recording overview links directly to it only when its record ID and source Xet identity agree. The companion overview also exposes the Pre-Standard recording, which is outside the Standard recording index.

Choose a recording and one of its 21 uniform positions, then use **Fit frame**, **Native pixels**, or **Open full-resolution PNG**. Source, native-pack and recording-access provenance links remain beside the selected frame. Only the selected PNG loads; source and proxy videos are links opened by explicit user action. Unknown records or invalid frame routes show an unavailable state without substituting a sample. Record/frame selections are shareable in the query string; zoom and scroll are not retained.

This companion uses the pinned pack's first-to-last packet-PTS targets. Its earlier JPEG profile uses duration targets, so equal position labels need not identify the same decoded frame. Documentary nulls describe the pinned pack; no work identity or capture completeness is inferred. The historical nine-record inspector, source revision, supplementary references and saved-location contracts are retained.

`native-source/` retains the exact three published JSON inputs, without media. `native-data.json` and `../assets/native-inspection-index.js` are reproducible projections generated by `node tools/build-native-companions.mjs` from the repository root. `node tools/build-native-companions.mjs --check` verifies their exact bytes against those source-bound inputs; CI runs this check. The GitHub projection does not replace Hugging Face source or derived manifests.
