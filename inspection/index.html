What this prototype does—and does not test

Nine requested positions span each file’s encoded presentation timestamps. The next available timestamp is used and checked against decoded output. Frames between samples are not shown. The strip is navigation, not a summary of every event or an estimate of physical drawing time.

Full-size PNGs preserve decoded RGB pixels after applying only the file’s declared display rotation. The selected-frame viewport has a separate reversible viewing rotation; it does not modify the PNG, source video, thumbnails, or photograph. The small strip uses resized JPEGs. No drawing-region crop, enhancement, alignment, completion estimate, or event label is applied.

The three cases were selected for access structure and practical local availability, not visual quality or representativeness. Photograph identity and file ordering retain their existing evidence. A selected work photograph is not an exact video endpoint.

Technical checks can establish correct links and displayed assets. Whether this interface helps human inspection remains a separate judgment; a passing test suite does not settle that.
