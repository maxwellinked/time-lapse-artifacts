# Data authority and publication

Hugging Face is the authoritative repository for Time-Lapse Artifacts data and
metadata: `https://huggingface.co/datasets/maxwellinked/time-lapse-artifacts`.
The Hugging Face derived repository holds published evidence derivatives.
This GitHub repository is a lightweight browser and reproducible projection.

- Create and maintain authoritative metadata fields, definitions, relationships,
  qualifications, and evidence on Hugging Face first. A browser-only label or
  JSON field does not complete a requested metadata enrichment.
- Update the affected canonical indexes, schema declarations, validators, and
  generated dataset tables together. Preserve source identities and all
  existing values unless the user authorizes a supported correction.
- Make GitHub consume and validate the published, revision-pinned Hugging Face
  values. Retained input snapshots, display indexes, and bounded previews are
  derived access aids, never a competing source of truth.
- Keep recording mode, acquisition protocol, encoded playback timing, observed
  physical timing, work identity, and candidate relationships distinct. Preserve
  uncertainty and evidence status in both the source and its display.
- Verify the source publication and its downstream projection before reporting
  the metadata update complete. Report publication status for each repository
  explicitly.

This is the user's stated architecture. Apply it to every future data or
metadata task in this repository.
